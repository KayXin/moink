墨印 MoInk 一键刷机包
版本：R1.3.0（固件与控制页共用同一个版本号；2026-10-13，api 保持 2）
================================================

本版三件事（多图轮播图库）：
  ① ★ 多图轮播 —— 设备最多存 8 张图，短按机身上的按键循环切换
                    （R1.2.0 预留的 store 存储分区本版正式启用）
  ② ★ 设备轮播图库 —— 控制页新增「设备轮播图库」卡片：
                    8 格缩略图、点缩略图看大图、× 删除单张、一键清空
  ③ ★ 上传即入轮播 —— 单图「上传并刷新屏幕」= 变成一张轮播图；
                    另加「仅上传」按钮：只入库不刷屏，连续加图更省事

（R1.2.2 的改动也在本版中：删「A1 驱动」二级菜单、GPIO 接法可配四档、
 MOS 自锁脚 GPIO2、升级不再重置设置、电量分压改 100k:100k。）

文件夹内容（放在同一个目录）：
  MoInk一键刷机.bat        双击运行（没装 Python 会引导自动安装）
  flash_on_pc.py           刷机脚本（bat 自动调用，也可命令行单独运行）
  moink_R1.3.0_merged.bin  固件整包（0x0 写入，含 bootloader + 分区表 + 固件）
  moink_R1.3.0_app.bin     OTA 升级包（设备已能开机时，在网页里上传）
  page-R1.3.0.html         创作页面（网页里「升级」上传，免刷机）
  test_frame_post.py       诊断工具（PC 直连发四色测试帧，验证显示链路）

怎么升到本版
------------------------------------------------
★ 本版分区表与帧格式都没变，所以从 R1.2.0 / R1.2.2 可以**直接网页 OTA**，
  不必线刷。只有 R1.2.0 之前的旧版本（R1.1.x 及更早）才必须用方式 B 线刷。

【推荐】方式 A：设备现在跑 R1.2.0 / R1.2.2，网页里直接升
  1. 控制页「设置 → 系统维护与升级」，把 moink_R1.3.0_app.bin 选进去
  2. 等设备重启完成（约 1 分钟）
  3. 重启后页面自动变成新版（控制页随固件一并更新），版本显示 R1.3.0。
     ★ 你已有的设置（屏型 / 休眠档 / 发射功率 / 热点 / GPIO 接法）都还在；
     ★ 已经存在的轮播图也还在（store 分区不受升级影响）。

方式 B：需要整包刷写 / 首次使用 / 从 R1.1.x 及更早升级
  1. 双击 MoInk一键刷机.bat。如果这台电脑没有 Python，
     会询问「是否自动下载并安装」，输入 y 回车即可。
  2. 用【数据线】（能传数据的，不是纯充电线）把板子接到电脑 USB 口。
  3. 双击 MoInk一键刷机.bat，等它自动选串口、自动刷写（约 1~2 分钟）。
     脚本只认带 VID 的真实 USB 串口，蓝牙等虚拟串口（无 VID）会自动跳过。
  4. 看到 [OK] 刷机完成即可。手机 Wi-Fi 连 MoInk-XXXX（默认开放）→
     浏览器打开 http://192.168.4.1

※ 方式 B 是整包覆盖写，会连分区表一起重写（相当于恢复出厂）。
※ 只想清掉设备里已有的轮播图，不用刷机：网页「设备轮播图库 → 清空轮播」即可。

★ 轮播图库怎么用
------------------------------------------------
添加：在「创作」页编辑好图片，点「上传并刷新屏幕」→ 图片存进轮播并立即显示；
      只想继续加图、不想每次刷屏，用旁边的「仅上传」。
      ★ 最多 8 张。满了以后上传会被拒绝（页面提示「轮播已满 8 张」），
        先删一张或点「清空轮播」再传。
管理：「设置 → 设备轮播图库」——
      · 8 个格子显示已有图片的缩略图（彩色），当前正在显示的那张有绿框；
      · 点缩略图 → 全屏大图预览，点「关闭预览」或点黑底退出；
      · 每个格子右上角 × → 删除这一张（后面几张会自动前移补位）；
      · 「清空轮播」→ 清掉全部（只清索引，不擦 flash，不伤设备）。
切换：在设备上**短按**按键（唤醒键）＝ 切到下一张。
      ★ 设备睡着时按一下唤醒，那一下也算一次短按，会直接切到下一张。
      **长按 5 秒**仍然是恢复出厂设置，别误按。

★ 网页里升级只需选文件，不用判断类型
------------------------------------------------
只有一个升级入口：
  · 传 moink_R1.3.0_app.bin（.bin）→ 固件升级：写备用分区 → 校验 → 切槽
    → 顺带更新控制页 → 清理废弃旧键（不重置你的设置）→ 自动重启
  · 传 page-R1.3.0.html（.html）→ 只热更控制页：CRC32 校验 → 替换
    → 不重启，刷新浏览器即可
设备按文件**内容**识别（固件首字节 0xE9 / 页面以 <!doctype 或 <html 开头），
不看后缀名，也不看浏览器报的类型。

★ GPIO 设置怎么用
------------------------------------------------
「设置 → GPIO 设置」四档：
  · 默认    —— 出厂接线（SCK=4 MOSI=6 CS=7 DC=1 RST=3 BUSY=10，唤醒=5，ADC=0）
  · 排线    —— SCK=7 MOSI=10 CS=6 DC=4 RST=3 BUSY=1，唤醒=5，ADC=0
  · 整合板  —— SCK=4 MOSI=3 CS=5 DC=6 RST=7 BUSY=10，唤醒=1，ADC=0
  · 自定义  —— 逐个下拉选 IO。已选过的 IO 会自动从其它下拉里去掉，避免撞车；
              电池 ADC 只能选 GPIO0~4（C3 的 ADC1 固定绑这几脚），
              唤醒键只能选 GPIO0~5（深睡只有这几个脚能唤醒）。
※ 改动 GPIO 必须重启才生效（SPI 总线与 ADC 通道只在开机时初始化），
  所以选完请点「保存并重启」，页面会先保存、再自动重启设备。
※ GPIO2 固定留给 MOS 自锁，不在这八个脚里出现。
※ 若你的设备是「排线」或「整合板」接法、且之前从 R1.2.1 及更早升上来，
  NVS 里可能还没有 GPIO 记录 → 会暂时落在「默认」档：进页面选对应档、
  点一次「保存并重启」即可，之后再升级不会复现。

硬件提醒（自锁脚）
------------------------------------------------
R1.2.2 起 GPIO2 被用作 MOS 一键开机自锁脚，上电后固件立即拉高、深睡前锁存电平。
  · 没有接自锁电路的板子：GPIO2 悬空或被固件拉高，不影响开机与显示。
  · 接了自锁电路：请按外部电路设计接，勿把 GPIO2 强拉低。

注意事项
------------------------------------------------
- 不要用浏览器网页烧录器！本板是 C3 原生 USB-JTAG（VID 0x303a），
  网页烧录器（WebSerial）会卡死在 "Stub running..."，一个字节都写不进。
- 如果卡死或失败：拔插一次 USB，然后在本目录打开命令行运行：
      python flash_on_pc.py --no-stub
- 查看本机全部串口：
      python flash_on_pc.py --list

★ 关于电量显示（分压比是写死在固件里的）
------------------------------------------------
本包固件按 **100k:100k 分压（×2.0）** 标定电量。若你的板子分压电阻不同
（例如此前的 470k:100k = ×5.7），电量数值会整体偏移，需要改 `src/power.c` 里的
`BAT_DIV_NUM` / `BAT_DIV_DEN` 后重新编译，否则会显示成「未连接」或明显不准。

刷完验证（六项）
------------------------------------------------
控制页「设置」设备状态应显示：版本 R1.3.0 / 接口 2。

□ V1 轮播添加（★本版重点）：
   编辑一张图 → 点「上传并刷新屏幕」→ 屏幕立即显示该图，
   「设备轮播图库」里出现 1 张缩略图（彩色、有绿框）。
   再编辑第二张 → 点「仅上传」→ 图库变 2 张，但**屏幕不变**（仍显示第一张）。
   再点「上传并刷新屏幕」传第三张 → 屏幕切到第三张，图库 3 张。

□ V2 按键切图：设备睡着后短按一次按键 → 唤醒并切到下一张（不是重显当前张）。
   连续短按，应在已有几张之间循环；**长按 5 秒**应恢复出厂（设置回默认、
   热点名回 MoInk-XXXX）。

□ V3 图库管理：点任意缩略图 → 弹出大图预览，方向/内容与屏上一致；
   点 × 删一张 → 该格消失、后面的图前移、张数 -1；
   删掉当前正在显示的那张后再按按键，不应出现花屏或空白；
   点「清空轮播」→ 8 格全空、张数归 0，屏幕保持最后一张（不清屏）。

□ V4 满 8 拒绝：连续加到 8 张后再「上传并刷新屏幕」→
   页面提示「轮播已满 8 张：请先删除或清空再上传」，且原图不被覆盖。

□ V5 升级兼容（可合并到日常使用）：
   本版可直接用 moink_R1.3.0_app.bin 网页 OTA（分区表未变）；
   升级后已有的轮播图与设置都应保留。

□ V6 回归（R1.2.2 已验收项，抽检即可）：
   GPIO 四档仍能正常切、「保存并重启」正常、A1 屏无需留白（四个留白勾请保持不勾）。

本版主要更新
------------------------------------------------
- ★ 轮播存储真正启用：8 槽 × 128 KB，每槽一张「帧头 + 2bpp 载荷」（槽尾可带缩略图）。
- ★ 新图**追加到末尾**；满 8 张返回 HTTP 507 拒绝（不再覆盖最早一张）。
- ★ 新增 /api/carousel/list（图库列表 + 缩略图）、/api/carousel/full（整帧，大图预览）、
  /api/carousel/delete（删除并紧凑）、/api/carousel/clear（只清索引不擦 flash）。
- ★ /api/frame 新增 query：save=1（存并显示）、save=1&noshow=1（只存不显示）、
  tlen=N（随帧携带网页生成的彩色 JPEG 缩略图）。
- ★ 短按 = 下一张（含深睡唤醒那一次），长按 5 s 仍为恢复出厂。
- 控制页新增「设备轮播图库」卡片与「仅上传」按钮；高级设置滑块旁的
  「默认」角标现在可以点击，一点即恢复该项默认值。
- 修复内部迭代期的一个严重问题：httpd 路由表容量不足会让设备一直重启
  （本版把上限提到 32，从根上解决）。
- api 保持 2：帧格式（16B 头 + 2bpp 载荷）零变动，可与 R1.2.x 互刷。

升级不兼容说明（重要）
------------------------------------------------
- 本版固件仍**没有** /api/ota 与 /api/web（R1.2.0 起删除）：R1.1.x 的旧页面
  无法升级本版设备，请使用本包里的页面。
- 反过来，R1.1.x 固件的设备上也没有 /api/upload：若把本包页面热更到
  那些设备再点升级，页面会提示「设备固件过旧，不含统一升级入口」——
  请先按方式 A / B 把固件升到 R1.2.0 及以上。
- **升级不重置用户设置**（屏型 / 左右镜像 / 休眠 / 唤醒 / 发射功率 /
  GPIO 接法），热点名与密码保留。唯一例外见上面「方式 A」里说的首次 GPIO 落档。
- ⚠️ 从 R1.1.x 升到 R1.2.x 及以后必须**线刷（方式 B）**，不能 OTA：R1.2.0 分区表有变
  （新增 store 存储分区），分区表只能整包线刷改写。R1.2.0 及之后可正常 OTA。
- 恢复内置页面按钮仍在（设置页「升级」下方），用于把热更的控制页清掉、
  回到固件内置的那一份。
